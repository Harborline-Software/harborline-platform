# Experimental rev6 first slice

The pure browser/Node module lives in `projections/shared/ui/hlp.ui.app-shell/rev6` and is shared by React Storybook and Blazor Blazing Story through JS interop. Both render the same neutral event corpus. The standalone slice catalog links the model observations and additive native tab-host stories without changing the live rev5 catalog or default shell. React exposes an explicitly named rev6 tab host through its aggregate facade; the Blazor package adds an explicitly named rev6 component and focus asset.

Run `node --test conformance/hlp.ui.app-shell/rev6/*.test.mjs` for the shared-state and light native-source checks.

Oracles: literal target lists and stable addresses from P1/P4/P9; explicit dirty-editor and owner-boundary properties from the approved first-slice clarification in staged rev6. Tests execute the reducer; fixture observations are not their own expected results. No mutation score is claimed.

Scope: tab dedupe, preview promotion and closure, dirty destruction requests, owner presentation isolation and retained work. Save exposes `saveRequest` with the original owner, unique requestId, tab id and draft generation. The adapter must echo those fields in `saved` after success. A failed save has no success event and retains the editor. Stale acknowledgments cannot close another owner's editor or a later draft generation. Cancel invalidates the request. `retain` models opaque owner-bound host data; it does not execute or authorize queued actions. Identity addresses use tuple serialization to avoid delimiter collisions. Sign-out removes only the active presentation pointer.

This is an in-memory model, not persistence or a security boundary. The host must own private state and API authorization. The paired native tab hosts render only the current owner's presentation, emit typed intents, and show a dirty-close prompt; Save is a request until an adapter acknowledges it. Native compilation, browser focus and accessibility checks, persistence, mode/group/docking behavior, full registry binding and gallery visual parity remain later gates. Existing ViewKindRegistry already supplies Kind/Renderer/RequiredRoles; this slice adds no alternate renderer registry. Its closed tab-kind list is only tab host validation and accepts no executable pack contribution.

The `AppShellRev6State` stories are model observations. The `AppShellRev6Native` stories are interactive component-source demonstrations using the same neutral scenarios. Native build, actual static-asset serving, gallery discovery and browser verification are intentionally deferred under the no-heavy-build instruction.
