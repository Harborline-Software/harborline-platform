# Harborline Blocks Inspection Review

Revision 2 freezes the narrow inspection-review orchestration contract over the packaged Forms Engine, Workflow contract, authenticated tenant/Party foundations, and Work Items kernel. It adds an explicit server-side authorization port and terminal decision receipt state before implementation consumers exist.

The package owns deterministic condition classification, form-instance-derived review identity, a closed admitted human-action process, same-tenant subject/query ports, and typed approve/rework mutations. It does not own UI, HTTP, an asset registry, a general workflow interpreter, or the broad inspections domain.

Distribution remains internal-only until public release and package authority are explicitly approved.
