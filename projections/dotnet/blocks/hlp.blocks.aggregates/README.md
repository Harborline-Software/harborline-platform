# Harborline.Blocks.Aggregates

Standalone, provider-neutral aggregation engine for revision-1 aggregate definitions.

The package owns validation, filtering, deterministic grouping, scalar folds, subtotals,
grand totals, bounds, and a neutral result model. Row acquisition, definition persistence,
and authorization are ports. It intentionally has no dependency on RuleRuntime, Forms,
Views, Reports, UI, ASP.NET, EF, SQL, or financial modules.

Distribution is `internal-only` until public release is separately authorized.
